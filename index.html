Cấu hình Google Sheets

Nhập thông tin kết nối để đồng bộ dữ liệu. Bạn có thể bỏ qua và dùng chế độ Demo với dữ liệu mẫu.

💡 Hướng dẫn nhanh:
  1. Tạo Google Sheets với 3 tab: Menu, Orders, Order_Items
  2. Trong Google Sheets, vào Tiện ích mở rộng → Apps Script
  3. Dán đoạn Apps Script từ file apps-script.js và Deploy làm Web App
  4. Copy URL Web App và dán vào ô trên
